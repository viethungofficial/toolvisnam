Cấu Hình Giao Diện

Google Drive Cloud Database

Hướng dẫn lấy đường dẫn Apps Script:
  1. Vào Google Drive -> Tạo mới -> Google Apps Script.
  2. Dán mã Script đồng bộ (ở khung chat bên trái).
  3. Bấm Deploy -> New Deployment (Loại: Web app).
  4. Đặt Quyền truy cập (Who has access) là Anyone.
  5. Copy đường dẫn URL Web App nhận được dán vào ô bên dưới.
